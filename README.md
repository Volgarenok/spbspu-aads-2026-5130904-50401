описание курсовой:

Работа с данными:

Log1p - логарифмирование данных в векторе с логарифмом по основанию 10
Data_corr - вывод корреляции данных в тензоре из N векторов, где N - натуральное число. Рассчитывает коэффицент Пирсона для каждого измерения
Feature_scale - нормализация данных в векторе. Добавил исключительно для корректной работы Логистической регрессии, тк там безумно важна нормализация
Read_dataset - считывание датасета из файла форматом .csv и .data
Save_data - сохранение изменений на датасете. по умолчанию сохраняется в формате .data
Feature_del - удаление признака из датасета
Data_split - разделение данных на данные/цель
Data_train_test_split - разделение данных на тестовые/тренировочные

Работа с моделями:

Load_model_linear - загрузка сохраненных весов для модели линейной регресии из файла .model формата
Load_model_logistic - загрузка сохраненных весов для модели логистической регресии из файла .model формата
Save_model_linear - сохранение весов модели линейной регрессии, по умолчанию в .model формате
Save_model_logistic - сохранение весов модели логистической регрессии, по умолчанию в .model формате
Log_loss_model_init - инициализация весов модели логистической регрессии по загруженному датасету
Linear_model_init - инициализация весов модели линейной регрессии по загруженному датасету
Model_linear_fit - обучение модели(настрока весов) линейной регрессии. Выбрал метод обучения - Градиентный спуск
Model_logistci_fit - обучение Логистической регрессии. Метод обучения всё ещё Градиентный спуск
Change_a - изменение коэффицента скорости обучения при помощи градиентного спуска. нужен для точных настроек.
Linear_model_predict_train - предикт линейной регрессии на основе загруженного датасета для тренировок
Linear_model_predict_test - предикт логистической регрессии на основе загруженного тестового датасета
Logistic_model_predict_train - предикт логистической регрессии на тренировочных данных
Logistic_model_predict_test - предикт логистической регрессии на тестовых данных
Save_predict - сохранение предикта моделей в формате .predict
Predict_liear - предикт линейной модели на введенных данных
Predict_logistic - предикт логистической модели на введённых данных
Model_linear_score - вывод среднеквадратичной ошибки линейной регрессии на предикте. Метрика - MSE
Model_linear_info - вывод весов загруженной модели линейной регрессии
Model_logistic_info - вывод весов загруженной модели логистической регрессии
data_head - вывод первых N строчек датасета или, если N > количества строчек датасета, вывод всего датасета
